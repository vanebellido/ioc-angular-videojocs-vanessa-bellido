# GameVault - Gestor de Videojocs

Aplicació web desenvolupada en Angular per a la gestió, consulta i seguiment de videojocs, corresponent a la pràctica d'Angular de l'IOC (EAC1).

## Descripció del projecte
Plataforma per consultar i gestionar informació sobre videojocs, estructurada mitjançant components, serveis i models d'Angular.

## Requisits del sistema
- Node.js (v18 o superior)
- npm
- Angular CLI
