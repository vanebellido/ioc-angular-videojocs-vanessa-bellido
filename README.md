# GameVault - Gestor de Videojocs

Aplicació web desenvolupada en Angular per a la gestió, consulta i seguiment de videojocs, corresponent a la pràctica d'Angular de l'IOC (EAC1 - RA2: Components i interfície d'usuari).

## Descripció del projecte
Plataforma per consultar i gestionar informació sobre videojocs, estructurada mitjançant components, models de dades, comunicació pare-fill, formularis amb validacions i control de flux modern.

## Requisits del sistema i versions
- **Node.js**: v20 o superior
- **Angular CLI**: v19 / v20
- **TypeScript**: v5.x
- **Gestor de paquets**: npm

## Branca de treball i lliurament
- **Branca activa**: `ra2-components`
